# 🎯 Aditi's IIT JAM Maths Streak Tracker

Welcome to the ultimate accountability tracker! This repository powers a custom web app designed to maintain momentum for the IIT JAM Mathematics exam.

## 📜 The Golden Rule
**50 Questions a Day. No Excuses.**
Whether it is grinding through rigorous Real Analysis proofs, solving complex Linear Algebra matrices, or tackling Group Theory, consistency is the only way to crack the JAM.

## ⚙️ How It Works
1. Solve 50 math questions daily.
2. Snap a photo of the final solved question.
3. Upload it to the tracker app.
4. Watch the streak grow. 

*Miss a calendar day, and the streak resets to zero. Protect the streak!* 🔥
